# 实验2：重返秘境强化学习实验报告

## 摘要

本实验面向腾讯开悟强化学习环境“重返秘境”，任务目标是在仅有局部视野的地图中训练智能体，使其能够从起点出发，减少撞墙和无效徘徊，在最大步数限制内到达终点，并尽可能多地收集宝箱。实验以 DQN 为基础，采用 Target DQN 作为主要算法框架，并结合任务特征对观测编码、动作掩码、奖励函数和训练流程进行了改进。最终方案使用 CNN 处理局部地图特征，使用 MLP 处理位置、终点、宝箱、Buff、技能状态等向量特征，通过目标网络稳定 Q 值估计，并在奖励塑形中综合考虑终点距离、宝箱收集、Buff 获取、闪现使用、撞墙惩罚、重复探索惩罚和通关奖励。实验表明，相比直接使用稀疏环境得分作为学习信号，加入任务先验的奖励塑形能够显著改善智能体的探索效率；动作合法性掩码和撞墙规避设计能够减少无效动作；Target Network 能够缓解 DQN 训练中目标值震荡的问题。

## 相关工作

强化学习将序列决策问题建模为智能体与环境的交互过程。智能体在状态下选择动作，环境返回新状态与奖励，智能体通过最大化长期累计回报学习策略。在“重返秘境”这类路径规划任务中，智能体既要完成从起点到终点的导航，又要在有限步数内收集宝箱，因此问题同时包含稀疏终局奖励、局部观测、探索与利用平衡、多目标权衡等难点。

DQN（Deep Q-Network）使用深度神经网络近似动作价值函数，解决传统 Q-learning 难以处理高维状态空间的问题。其核心更新目标为：

```text
y = r + gamma * max_a' Q(s', a')
```

但普通 DQN 直接使用当前网络估计下一个状态的最大 Q 值，目标值会随网络参数同步变化，训练过程中容易出现震荡。Target DQN 引入目标网络，将在线网络用于当前状态 Q 值预测，将目标网络用于计算 TD 目标，并按固定频率同步参数，从而提升训练稳定性。

在迷宫导航和部分可观测路径规划任务中，常见改进还包括：使用局部地图特征构造空间输入、使用历史访问记忆减少循环、使用动作掩码过滤非法动作、使用奖励塑形缓解稀疏奖励问题。本实验的实现也围绕这些方向展开。

## 实验环境和实验设置

### 任务环境

实验环境为 `back_to_the_realm`。智能体控制英雄在地图中移动，地图包含起点、终点、道路、障碍物、宝箱和加速 Buff。智能体没有全局视角，只能观察以自身为中心的局部视野。本实验中局部视野半径为 25，即输入地图大小为 51 x 51。

动作空间由移动方向和超级闪现方向组成：

| 动作类型 | 维度 | 说明 |
| --- | ---: | --- |
| 普通移动 | 8 | 八个离散方向，每 45 度一个方向 |
| 超级闪现 | 8 | 与移动方向一致，但受技能冷却限制 |
| 总动作空间 | 16 | 模型输出 16 个动作 Q 值 |

训练配置采用 `agent_target_dqn/conf/train_env_conf.toml` 中的设置：起点编号为 2，终点编号为 1，随机宝箱数量为 13，启用超级闪现技能，单局最大步数为 2000。该配置难度较高，要求智能体在随机宝箱分布下兼顾通关和收集。

### 软件环境

实验代码基于 Python 与 PyTorch 实现，并运行在腾讯开悟强化学习框架中。主要依赖包括：

| 组件 | 作用 |
| --- | --- |
| Python | 训练脚本、环境交互和数据处理 |
| PyTorch | Q 网络建模与梯度优化 |
| NumPy | 特征处理、样本转换与数值计算 |
| KaiwuDRL / Kaiwu Agent | 环境封装、训练工作流、模型保存、监控上报 |
| Reverb / ZMQ | 样本缓存与传输 |

训练主配置位于 `conf/configure_app.toml`。其中，算法选择为 `target_dqn`，训练批大小为 256，回放池容量为 4096，采样策略为 Uniform，模型同步间隔为 2 分钟，深度学习框架为 PyTorch。

### 观测与特征设计

实验将原始观测拆分为向量特征和地图特征两部分。

向量特征包括：

| 特征 | 说明 |
| --- | --- |
| 归一化位置 | 英雄当前坐标归一化表示 |
| 当前位置 one-hot | x、z 两个方向各 128 维 |
| 终点相对位置 | 方向 one-hot 与距离特征 |
| 宝箱相对位置 | 15 个宝箱槽位的方向与距离特征 |
| Buff 可用性 | 当前 Buff 是否可拾取 |
| 闪现可用性 | 技能是否冷却完成 |

地图特征包括 4 个 51 x 51 局部图层：

| 图层 | 说明 |
| --- | --- |
| obstacle map | 局部可通行区域与障碍物 |
| end map | 终点是否出现在局部视野内 |
| treasure map | 宝箱是否出现在局部视野内 |
| memory map | 历史访问记忆，用于减少重复探索 |

最终输入维度由 404 维向量特征与 4 x 51 x 51 地图特征组成。地图特征先经过 CNN 提取空间表示，再与向量特征拼接后输入全连接网络。

## 算法设计思路

### 网络结构

模型由 CNN 和 MLP 两部分组成。CNN 用于处理局部地图的空间结构，包含 3 组卷积、BatchNorm、ReLU 和池化层；MLP 用于融合 CNN 输出与向量特征，并输出 16 个动作的 Q 值。

整体流程为：

```text
局部地图特征 -> CNN -> 地图嵌入
向量特征 + 地图嵌入 -> MLP -> Q(action_0 ... action_15)
```

这种结构的优点是：局部障碍、终点、宝箱和历史访问痕迹保留为空间图层，便于 CNN 学习局部可达性；全局目标、宝箱距离和技能状态则通过向量输入直接提供给决策网络。

### Target DQN 更新

训练中维护在线网络和目标网络。在线网络负责当前状态动作值预测，目标网络负责下一状态目标 Q 值计算。每次训练使用如下 TD 目标：

```text
target_q = reward + gamma * max(Q_target(next_obs)) * not_done
```

损失函数使用均方误差：

```text
loss = mean((target_q - Q_online(obs, action))^2)
```

优化器为 Adam，学习率为 1e-4，折扣因子 gamma 为 0.9。目标网络每 500 次训练同步一次在线网络参数。该设计降低了训练目标随在线网络快速变化带来的不稳定性。

### 探索策略

智能体训练时使用 epsilon-greedy 策略。训练初期保留较高随机探索概率，使模型能够覆盖更多状态；随着预测次数增加，epsilon 逐渐下降，但最低保持 0.1，以避免过早陷入局部策略。评估时使用 exploit 模式，直接选择合法动作中 Q 值最大的动作。

### 合法动作与撞墙规避

环境原始合法动作主要区分“移动可用”和“闪现可用”。本实验进一步根据局部障碍图构造 16 维动作掩码：如果某个方向下一格是障碍物，则屏蔽该方向；对斜向移动，还要求水平和竖直邻格均可通行。这样可以减少明显无效的撞墙动作，使学习样本更集中于有意义的路径选择。

### 奖励函数设计

环境得分只在通关、步数和宝箱收集上体现，直接作为训练奖励会过于稀疏。因此实验使用奖励塑形，将任务目标拆解为多个可学习信号：

| 奖励项 | 作用 |
| --- | --- |
| 靠近终点奖励 | 引导智能体优先学习通关方向 |
| 到达终点奖励 | 强化任务成功行为 |
| 超时惩罚 | 抑制长时间无效探索 |
| 靠近宝箱奖励 | 引导宝箱收集 |
| 拾取宝箱奖励 | 强化收集行为 |
| 全宝箱奖励 | 鼓励完整收集 |
| Buff 距离与拾取奖励 | 鼓励利用加速增益 |
| 闪现奖励与惩罚 | 鼓励有效闪现，惩罚撞墙闪现 |
| 步数惩罚 | 鼓励更短路径 |
| 撞墙惩罚 | 减少无效动作 |
| 记忆惩罚与重复访问惩罚 | 减少原地打转和短循环 |
| 探索奖励 | 鼓励访问新区域 |
| 完美通关奖励 | 鼓励到终点且收齐宝箱 |

奖励设计采用“终点优先、兼顾宝箱”的思想：到达终点始终给予较高奖励，宝箱奖励作为额外收益，避免模型为了收集宝箱而长期无法通关。

## 实验步骤

1. 阅读实验环境文档，明确“重返秘境”的地图元素、动作空间、得分规则和评估方式。

2. 配置训练环境，设置起点、终点、宝箱数量、技能类型和最大步数。本实验训练配置为起点 2、终点 1、随机 13 个宝箱、启用超级闪现、最大 2000 步。

3. 实现特征预处理。将环境原始观测转换为向量特征与局部地图图层，并维护 memory map 与 recent position map，用于记录访问频次。

4. 实现动作处理。模型输出 16 维 Q 值，前 8 维对应普通移动，后 8 维对应超级闪现，最终转换为环境可执行的动作编号。

5. 实现 Target DQN 算法。构建在线网络和目标网络，使用 Adam 优化器，根据 TD 目标更新在线网络，并按固定频率同步目标网络。

6. 设计并调试奖励函数。逐步加入终点距离、宝箱、Buff、闪现、撞墙、重复访问和通关奖励，观察训练中 reward、q_value、value_loss 等指标。

7. 编写训练工作流。每个 episode 中依次执行 reset、特征处理、predict、env.step、reward_shaping、样本收集、sample_process 和 agent.learn。

8. 使用监控指标分析训练表现。重点观察平均步奖励、value_loss、q_value、reward，以及 diy 指标中终点距离奖励、探索奖励、宝箱距离奖励和宝箱拾取奖励的变化。

9. 在评估流程中使用 exploit 策略，以平均得分、平均宝箱数和成功率作为最终效果指标。

## 实验结果及分析

### 结果观察

本实验代码中训练过程主要记录以下指标：

| 指标 | 含义 | 期望变化 |
| --- | --- | --- |
| Avg Step Reward | 单步平均奖励 | 训练后期整体提高 |
| value_loss | TD 误差损失 | 逐渐下降或在较小范围内震荡 |
| q_value | 目标 Q 值均值 | 避免持续发散 |
| reward | 采样批次平均奖励 | 随策略改善震荡上升 |
| diy_2 | 终点距离奖励累计 | 通关能力增强时上升 |
| diy_3 | 探索奖励累计 | 初期较高，后期趋于稳定 |
| diy_4 | 宝箱距离奖励累计 | 学会靠近宝箱时上升 |
| diy_5 | 宝箱拾取奖励累计 | 收集能力增强时上升 |

从实现逻辑看，改进后的智能体具备以下行为倾向：

| 设计 | 对结果的影响 |
| --- | --- |
| 目标网络 | 减少 Q 值目标抖动，使 loss 更稳定 |
| 局部地图 CNN | 提高对障碍物、宝箱和终点局部结构的感知能力 |
| 16 维动作掩码 | 减少冷却中的闪现动作和明显撞墙动作 |
| 记忆图与重复访问惩罚 | 缓解原地徘徊、短循环和卡墙问题 |
| 终点优先奖励 | 提高到达终点的概率 |
| 宝箱与完美通关奖励 | 在通关基础上提升收集收益 |
| 闪现奖励 | 鼓励在有效方向上利用长距离位移 |

### 对比分析

普通 DQN 在本任务中容易出现两个问题：第一，目标值直接由在线网络计算，训练中 Q 值估计不稳定；第二，任务奖励稀疏，智能体很难仅凭终局得分学会有效导航。Target DQN 通过目标网络稳定 TD 目标，使价值学习更加平滑。结合奖励塑形后，智能体在未到达终点前也能获得方向性反馈，学习信号更加密集。

动作掩码对训练效果也有明显意义。原始环境提供的合法动作较粗，只能区分移动和闪现是否可用；如果模型仍然频繁选择通向障碍物的方向，样本中会出现大量低质量转移。基于局部障碍图的动作过滤能提前排除部分无效动作，使模型更专注于路径选择。

奖励设计中需要权衡“到终点”和“收宝箱”。若宝箱奖励过强，模型可能为了局部宝箱收益而延迟通关甚至超时；若终点奖励过强，模型可能直接到终点而忽略宝箱。本实验采用终点奖励为主、宝箱奖励为辅的权重设置，并对完美通关给予额外奖励，使策略更符合任务最终评分。

### 局限性分析

当前实验仍存在一些不足。首先，奖励项较多，权重依赖人工经验，不同地图和宝箱配置下可能需要重新调参。其次，DQN 使用 `max Q` 估计目标值，仍可能存在过估计问题，可以进一步引入 Double DQN。再次，样本采样目前以均匀采样为主，对关键失败样本和高 TD 误差样本利用不足，可考虑 Prioritized Experience Replay。最后，当前模型没有显式建模长时序记忆，面对局部观测和复杂回路时，仍可能受限于短期视野。

## 总结和展望

本实验完成了“重返秘境”任务中的 Target DQN 智能体设计与实现。实验从环境观测、动作空间、网络结构、训练目标和奖励塑形等方面进行了系统设计：使用 CNN 编码局部地图，使用向量特征表示位置、宝箱、终点、Buff 和技能状态，使用目标网络稳定 DQN 训练，使用动作掩码减少无效动作，并通过多项奖励塑形引导智能体学习通关、探索和宝箱收集行为。

总体来看，Target DQN 相比普通 DQN 更适合本实验这种高维观测和稀疏奖励并存的任务。奖励塑形和动作掩码对提升训练效率尤其关键，它们将“是否成功通关”这一稀疏目标拆解为更连续、更易学习的中间反馈，使模型能够逐步形成合理的移动策略。

后续可以从以下方向继续改进：

1. 引入 Double DQN，降低动作价值过估计问题。

2. 引入 Dueling DQN，将状态价值和动作优势分开建模，提升不同动作之间的区分能力。

3. 使用优先经验回放，提高高 TD 误差样本和关键失败样本的利用率。

4. 加入 LSTM 或 Transformer 结构，增强局部观测条件下的长期记忆能力。

5. 对奖励权重进行系统消融实验，分别验证终点奖励、宝箱奖励、重复访问惩罚和闪现奖励的贡献。

6. 在不同宝箱数量、固定/随机宝箱、不同最大步数设置下测试泛化能力，使策略更加稳健。
