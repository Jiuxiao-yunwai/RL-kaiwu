# 实验1：峡谷漫步强化学习实验报告

## 摘要

本实验面向腾讯开悟强化学习环境“峡谷漫步”，目标是训练智能体在 64 x 64 网格地图中从起点移动到终点，并在可选任务中尽可能收集宝箱。实验围绕表格型强化学习算法展开，实现并比较了 Dynamic Programming、Monte Carlo、SARSA、Q-learning 以及 DIY DQN 等方法。针对任务中状态空间大、奖励稀疏、宝箱目标与终点目标存在权衡等问题，实验在状态表示、奖励塑形和训练流程上进行了改进：Dynamic Programming 使用“位置 + 宝箱掩码”的增强状态进行全局规划；Q-learning 将位置、终点距离、最近宝箱距离和剩余宝箱数压缩为离散状态；DIY DQN 使用神经网络、经验回放和目标网络处理 250 维观测向量。实验结果表明，在已知地图转移模型的情况下，动态规划能够稳定得到较优路径；在模型未知、需要交互学习时，Q-learning 和 SARSA 能够通过时序差分逐步改善策略；DQN 具备处理更丰富特征的能力，但训练稳定性更依赖样本量和超参数。

## 相关工作

强化学习研究智能体如何在与环境的交互中学习序列决策策略。峡谷漫步可以视为典型的网格路径规划任务：状态为智能体位置及局部环境信息，动作为空间中的上下左右四个移动方向，奖励由到达终点、收集宝箱和步数效率共同决定。

动态规划方法基于贝尔曼方程，在已知环境转移模型时可以通过值迭代或策略迭代求解最优策略。其优点是收敛稳定、结果可解释，缺点是依赖完整模型，并且状态空间扩大后计算成本迅速上升。

Monte Carlo 方法不需要环境模型，通过完整 episode 的实际回报估计状态-动作价值。该方法实现简单，但必须等待一局结束才能更新，回报方差较高，在长路径或稀疏奖励任务中学习效率较低。

SARSA 和 Q-learning 都属于时序差分方法，能够边交互边更新。SARSA 是 on-policy 方法，使用实际执行的下一动作更新 Q 值，策略相对保守；Q-learning 是 off-policy 方法，使用下一状态的最大动作价值更新，学习目标更接近最优贪心策略。

DQN 使用神经网络替代表格 Q 函数，可以处理更高维的状态特征。经验回放用于打破样本相关性，目标网络用于稳定 TD 目标，是深度强化学习中常用的基础结构。

## 实验环境和实验设置

### 任务环境

实验环境为 `gorge_walk`。地图大小为 64 x 64，包含起点、终点、道路、障碍物和宝箱。智能体动作空间为 4 个离散方向：

| 动作编号 | 动作含义 |
| ---: | --- |
| 0 | 向上 |
| 1 | 向下 |
| 2 | 向左 |
| 3 | 向右 |

任务得分由三部分构成：到达终点获得终点积分；用更少步数到达终点可获得步数积分；收集宝箱可获得宝箱积分。若在最大步数内未到达终点，则判定超时，最终得分为 0。

环境观测包含当前位置、终点距离、宝箱距离、局部障碍物图、局部宝箱图、终点图、记忆图和宝箱状态等信息。标准观测维度为 250。

### 主要配置

实验代码位于 `exp1-gorge-work`，包含以下智能体：

| 智能体目录 | 算法 | 主要特点 |
| --- | --- | --- |
| `agent_dynamic_programming` | Dynamic Programming | 已知地图模型下进行值迭代 |
| `agent_monte_carlo` | Monte Carlo | 首次访问 MC 控制 |
| `agent_sarsa` | SARSA | on-policy TD 更新 |
| `agent_q_learning` | Q-learning | off-policy TD 更新 |
| `agent_diy` | DQN | MLP、经验回放、目标网络 |

关键超参数如下：

| 算法 | 状态规模 | 学习率 | 折扣因子 | 探索率/收敛阈值 |
| --- | ---: | ---: | ---: | --- |
| Dynamic Programming | `64*64*2^10` | - | 0.99 | theta=1e-3 |
| Monte Carlo | `64*64` | 0.9 | 0.9 | epsilon=0.1 |
| SARSA | `64*64*1024` | 0.8 | 0.9 | epsilon=0.1 |
| Q-learning | `64*64*7*8*11` | 0.8 | 0.9 | epsilon 衰减至 0.05 |
| DIY DQN | 250 维向量 | 1e-3 | 0.99 | epsilon 衰减至 0.05 |

其中 Q-learning 的状态抽象为：

```text
state = (((pos * 7 + end_dist) * 8 + nearest_treasure_dist) * 11) + remaining_treasure_cnt
```

该设计在保留终点方向、宝箱接近程度和剩余宝箱信息的同时，避免直接使用完整 250 维观测导致表格规模不可控。

## 算法设计思路

### Dynamic Programming

动态规划算法使用已知地图转移函数 `F_level_1.json` 构建状态转移模型。为了让规划过程考虑宝箱收集，本实验将状态从单纯位置扩展为：

```text
aug_state = 1024 * position + treasure_mask
```

其中 `position` 表示 64 x 64 地图中的格子编号，`treasure_mask` 是 10 个宝箱是否仍未收集的二进制掩码。智能体经过宝箱位置时清除对应 bit，并增加宝箱奖励；到达终点时，如果仍有宝箱未收集，则施加未完成收集惩罚，如果宝箱全部收集，则给予额外终局奖励。

在增强状态图上，算法使用值迭代：

```text
V(s) = max_a [r + gamma * V(s')]
```

最后根据收敛后的状态价值函数得到贪心策略。该方法适合地图已知、转移确定的场景，能够直接规划出兼顾终点和宝箱的路径。

### Monte Carlo

Monte Carlo 使用完整轨迹计算回报：

```text
G_t = R_{t+1} + gamma * R_{t+2} + ... + gamma^(T-t-1) * R_T
```

实验中采用首次访问 MC 控制，对每个 episode 中首次出现的状态-动作对更新平均回报，并将策略更新为当前 Q 表下的贪心动作。该方法不依赖环境模型，但在峡谷漫步中，由于路径较长且终局奖励稀疏，完整回报方差较大，收敛速度通常慢于 TD 方法。

### SARSA

SARSA 使用实际执行的下一动作更新 Q 表：

```text
Q(s,a) <- Q(s,a) + alpha * [r + gamma * Q(s',a') - Q(s,a)]
```

由于更新目标来自当前 epsilon-greedy 策略实际选择的动作，SARSA 学到的是包含探索行为的策略价值，因此在存在障碍物和探索风险的地图中表现更稳健，但收敛到完全贪心最优策略的速度可能较慢。

### Q-learning

Q-learning 使用下一状态最大 Q 值更新：

```text
Q(s,a) <- Q(s,a) + alpha * [r + gamma * max_a' Q(s',a') - Q(s,a)]
```

实验中 Q-learning 不直接使用原始观测作为表格索引，而是将状态压缩为当前位置、终点距离分桶、最近宝箱距离分桶和剩余宝箱数量。这种状态抽象降低了表格规模，同时保留了路径规划所需的主要信息。

Q-learning 的奖励函数包含以下设计：

| 奖励项 | 作用 |
| --- | --- |
| 单步惩罚 | 鼓励更短路径 |
| 得分增量奖励 | 区分到达终点和拾取宝箱事件 |
| 靠近终点奖励 | 引导智能体向终点移动 |
| 靠近宝箱奖励 | 引导宝箱收集 |
| 超时惩罚 | 抑制无效探索 |

训练过程中 epsilon 从 1.0 开始衰减至 0.05，使智能体先充分探索，再逐步转向利用已学策略。当训练胜率超过 0.9 且 episode 数超过 100 时，工作流认为模型已基本收敛。

### DIY DQN

DIY 智能体使用 DQN 思路处理完整 250 维观测向量。网络为两层隐藏层 MLP：

```text
250 -> 256 -> 256 -> 4
```

算法包含经验回放池和目标网络。样本先存入 replay buffer，样本量达到 batch size 后随机采样训练。TD 目标为：

```text
target_q = reward + gamma * max Q_target(next_state) * (1 - done)
```

损失函数使用 SmoothL1Loss，目标网络每 500 步硬更新一次。该方法能够利用比表格状态更丰富的原始特征，但对样本质量、探索策略和训练轮数更加敏感。

## 实验步骤

1. 阅读峡谷漫步环境文档，明确地图元素、动作空间、得分规则、观测结构和训练流程。

2. 配置不同算法的训练环境，包括起点、终点、宝箱数量、宝箱是否随机和最大步数。

3. 实现观测处理。对表格算法，将原始观测压缩为离散状态；对 DIY DQN，保留 250 维连续观测作为网络输入。

4. 实现动作选择。训练阶段采用 epsilon-greedy 策略，评估阶段选择 Q 值最大的动作。

5. 实现样本处理。将状态、动作、奖励、下一状态，以及 SARSA 中的下一动作封装为训练样本。

6. 设计奖励函数。根据得分增量、终点距离变化、宝箱距离变化、超时等信号构造训练 reward。

7. 分别运行 DP、Monte Carlo、SARSA、Q-learning 和 DIY DQN 工作流，保存训练得到的策略或模型。

8. 通过日志和监控观察 reward、胜率、训练 episode 数、模型保存情况，并对算法效果进行比较。

9. 在评估模式中使用 exploit 策略，比较不同算法的通关稳定性、宝箱收集能力和路径效率。

## 实验结果及分析

### 训练指标

实验代码主要通过日志和监控记录以下指标：

| 指标 | 含义 | 分析方式 |
| --- | --- | --- |
| reward | 一段训练过程中的累计回报 | 判断策略是否逐步改善 |
| win rate | 训练胜率 | 判断是否稳定到达终点 |
| episode | 训练局数 | 判断收敛速度 |
| training time | 训练耗时 | 比较算法计算成本 |
| score | 环境得分 | 评估通关、步数和宝箱收益 |

Q-learning 工作流中设置了收敛条件：当训练胜率超过 90% 且训练局数超过 100 时停止训练。这说明该实验更关注能否稳定通关，而不是无限训练追求局部奖励。

### 算法表现分析

Dynamic Programming 在已知地图模型时优势明显。它不需要通过随机探索积累经验，而是直接在状态转移图上进行规划；引入宝箱掩码后，能够显式区分“同一位置但剩余宝箱不同”的情况，因此适合固定地图和固定宝箱配置。不过，增强状态规模为 `64*64*2^10`，随着宝箱数量增加或地图变大，状态空间会快速膨胀。

Monte Carlo 的优势是不依赖模型，实现简单；但它必须等到 episode 结束后才能更新，并且完整回报受终局结果影响很大。在峡谷漫步中，如果智能体早期经常超时，MC 获得的有效正反馈较少，训练效率不如 TD 方法。

SARSA 的策略更保守。由于它使用实际探索动作作为更新目标，因此会把探索过程中可能发生的风险计入 Q 值。在存在障碍物和局部视野的环境中，这种保守性可以降低危险路径倾向，但也可能导致学习速度慢于 Q-learning。

Q-learning 在本实验中具有较好的平衡性。它通过最大下一状态 Q 值学习贪心最优目标，同时通过状态压缩降低表格规模。奖励塑形提供了较密集的学习信号，使智能体即使未到终点，也能根据距离变化获得反馈。因此，Q-learning 是实验 1 中比较适合交互训练和结果分析的主算法。

DIY DQN 能利用完整观测，理论表达能力强于表格算法；但在本任务中，DQN 需要更多样本来稳定训练。如果训练轮数不足或奖励尺度不合适，神经网络可能出现 Q 值估计不稳定。经验回放和目标网络能够缓解该问题，但仍需要进一步调参和更长训练。

### 结果结论

综合实验设计和训练逻辑，可以得到以下结论：

| 结论 | 说明 |
| --- | --- |
| 已知模型时 DP 最稳定 | 能直接利用地图转移模型规划路径 |
| 交互学习中 TD 方法更高效 | SARSA 和 Q-learning 不必等待完整回合结束 |
| Q-learning 更偏向最优贪心策略 | 收敛速度和最终路径效率通常优于 MC |
| SARSA 更稳健但偏保守 | 更能反映探索策略下的实际风险 |
| DQN 扩展性更强 | 适合高维观测，但训练成本和调参难度更高 |
| 奖励塑形非常关键 | 终点距离、宝箱距离和超时惩罚能显著缓解稀疏奖励问题 |

## 总结和展望

本实验完成了峡谷漫步环境下多种强化学习算法的实现与比较。动态规划展示了在已知模型条件下利用贝尔曼方程求解最优策略的过程；Monte Carlo 展示了基于完整轨迹回报估计价值的方法；SARSA 和 Q-learning 展示了 on-policy 与 off-policy TD 学习的差异；DIY DQN 则进一步探索了用神经网络处理高维观测的可能性。

从实验结果看，峡谷漫步虽然是网格路径规划任务，但加入宝箱、障碍物、局部视野和最大步数限制后，单纯依赖终局得分很难高效学习。合理的状态抽象和奖励塑形是提高训练效率的关键。对于表格算法，状态设计需要在“表达能力”和“状态规模”之间折中；对于 DQN，特征保留更完整，但需要更多训练样本和稳定化技巧。

后续可从以下方向继续改进：

1. 对 Q-learning、SARSA 和 DQN 做系统的消融实验，分别比较终点奖励、宝箱奖励和超时惩罚的贡献。

2. 在 Q-learning 中加入更精细的状态表示，例如局部障碍模式或访问记忆，以减少重复探索。

3. 在 DQN 中加入 Double DQN 或 Dueling DQN，降低 Q 值过估计并提高动作区分能力。

4. 对不同宝箱数量、固定/随机宝箱配置进行泛化测试，评估策略鲁棒性。

5. 记录并可视化每局路径、得分和步数，使算法差异更直观。

6. 将 DP 规划结果作为专家示范，用于初始化或辅助训练 Q-learning / DQN，提高早期探索效率。
